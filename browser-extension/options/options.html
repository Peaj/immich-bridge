Immich Bridge

Immich Bridge is an unofficial integration for Immich and is not affiliated with or endorsed by the Immich project.

Connect this extension to your Immich web app. Access is requested only for the Immich site you enter here.

Local file actions require the Immich Bridge desktop companion app. When you click an Immich Bridge action, the extension passes only the selected asset path to that local app through the immich-bridge:// protocol. It does not send page content, asset paths, or telemetry to remote servers.
