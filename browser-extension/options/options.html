Immich Bridge

Connect this extension to your Immich web app. Access is requested only for the Immich site you enter here.

Open Immich

Desktop companion app required

Install the Immich Bridge desktop companion app once to enable Explorer and Open With actions from Immich.

Download companion app

When you click an Immich Bridge action, the extension passes only the selected asset path to the local companion app through the immich-bridge:// protocol. It does not send page content, asset paths, or telemetry to remote servers.

Immich Bridge is an unofficial integration for Immich and is not affiliated with or endorsed by the Immich project.
