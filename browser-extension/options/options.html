Folders on this computer

Reveal in Explorer, Copy original, and Open with find photos from Immich's external libraries through these folder mappings. Photos in Immich's own upload library don't need one; they open as read-only copies.

Open a photo from your external library in Immich, open its info panel, expand Details, click Show file location, and copy the full file path. Immich Bridge then looks for the same file on this computer.

    When you click an Immich Bridge action, the extension passes only the selected asset path to the local companion app, through native messaging or the immich-bridge:// protocol. Folder mappings set up on this page are stored only by the local companion app. Nothing is sent to remote servers, and there is no telemetry.
